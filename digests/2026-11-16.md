## 🤖 AI / Agent

### 1. hitkeeen/blender-ai-mcp-addon 【AI / Agent】
给 Blender 装上 AI 大脑的插件 + MCP Server：可以直接用自然语言对话操作 3D 场景，支持多 Agent 工作流。4 天 1.2k★，是本周"Blender + AI"热度的源头。有意思的是它一天内被克隆出 10 多个仿冒仓库（每个都是 500★ 左右、同日创建、文案雷同），克隆速度堪比病毒式传播——认准原仓库就好。

### 2. deepseek-ai/chat-demo 【AI / Agent】
DeepSeek 官方放出的前端聊天界面 Demo（TypeScript）。4 天狂揽 3k★，想自建一个类 DeepSeek 体验的聊天前端，这份官方参考实现是最快起点。官方下场开源前端Demo，这个动作本身就值得留意。

### 3. NVIDIA/SkillEvaluator 【AI / Agent】
NVIDIA 出的 Agent 技能评测框架：带质量门禁、语义重复检测、合成评测数据生成，还能"实弹"评测——直接测量一个 skill 装到 Agent 身上到底改变了多少行为。今天 +122★ 新上榜。当"Skills"成为 Agent 生态新风口，评测工具也开始成体系了。

### 4. elementalsouls/Claude-BugHunter 【AI / Agent · 安全】
一套给 Claude Code 用的红队/挖洞技能包：82 个 skills、15 个斜杠命令，沉淀了 681 份公开漏洞报告的模式，覆盖 24 类核心漏洞。6.5k★，今日 +98★ 新上榜。把众测经验做成结构化技能喂给 Agent，思路比工具本身更值钱。

## 🛠️ 开发工具 / 效率

### 5. rivet-dev/open-orange 【开发工具 / 基础设施】
把 Cloudflare Workers 和 Durable Objects 原封不动跑在自己服务器上（AWS/GCP/Azure 均可）。4 天 592★。写一次 Workers 代码，本地/私有云随便部署，等于给 Cloudflare 生态开了个"后门"，Serverless 爱狂喜。

### 6. DevedevT/FFmpeg-GUI-Editor-Windows 【开发工具 / 效率】
轻量便携的 FFmpeg 图形界面 + 无损视频裁剪器，Windows 直接下 .exe 就能用。4 天 1.2k★。命令行剪视频是无数人的痛点，这个"绿松石级"小工具精准戳中，TypeScript 社区之外难得的 VB.NET 选手。

### 7. berkantay/gpucanvas 【开发工具 / 可视化】
把成千上万个"活的 DOM 节点"放到无限画布上：GPU 负责绘制，DOM 负责可选中/可编辑。4 天 482★。在大规模可视化编辑器这个老大难问题上给出了新解法，前端性能控值得一读。

## 🎮 好玩 / 有趣

### 8. Noniv/abyssal-garden 【好玩 / 可视化】
一个可以在浏览器里"游泳穿越"的梦幻海底世界：摇曳的海带森林、光柱、超现实的场景，纯 JavaScript 实现。4 天 1.1k★。没有 AI、没有框架营销，纯粹靠"美"冲上热度榜，是今天最治愈的一个仓库。

### 9. opencoredev/islandcn 【好玩 / 前端】
开源版"灵动岛"组件，React + shadcn 一条命令装进你的网页。4 天 733★。苹果灵动岛的网页开源复刻，可以做通知提醒、任务进度等花活，给产品 UI 加彩蛋神器。

### 10. ZiChuanLan/freebie-radar 【好玩 / 效率】
"白嫖资源聚合雷达"：57 个源定时采集，AI 二审过滤假福利，还按抽奖/试用/推广分级隔离，通过 Telegram 即时推送。4 天 811★。国产项目，把"薅羊毛"这件事工程化了，AI 用在生活杂事上比用在写代码上可能更接地气。
